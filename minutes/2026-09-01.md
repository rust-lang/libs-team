thomcc: we say in the docs that if this function returns `true`, calling them is equivalent. They might have the same code but not be equivalent -- e.g. differ in provenance, one has a UB case, LLVM could

The 8472: Shouldn't all the information that distinguises this be erased at the time it could prove that they're equal?
